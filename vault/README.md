# Vault

This directory is the **personal workspace** the agent's filesystem tools can read and write.
It is intentionally excluded from version control (see `.gitignore`); only this `README.md`
and the `.gitignore` are tracked.

Add your notes, documents, and knowledge-base files here. The model can list, read, and search
them automatically, and create/modify/move/delete them only after you approve each mutation in
the browser.

Because the whole directory is private, you can keep anything personal here without worrying
about what gets published.
